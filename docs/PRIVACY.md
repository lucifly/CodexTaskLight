# 隐私说明

[返回 README](../README.md)

## 程序会读取什么

为展示任务状态，程序会读取当前用户本机的：

- 默认 `~/.codex` 目录中的任务索引：任务编号、标题及日志路径。
- 相关任务日志：生命周期事件、结构化确认请求及对应回复。
- 桌面端本地 IPC 快照和增量推送：运行状态及待处理请求。

日志和快照可能包含聊天上下文，因此程序在处理过程中可能接触到这些本机数据。它不会将完整聊天快照持续保留为状态，也不把聊天内容另存为文件或上传。

## 会写入什么

程序通过 `UserDefaults` 保存悬浮窗位置和相关界面偏好。编译脚本会写入本地 `dist/` 和临时编译缓存；图标工具会写入 `Assets/` 并清理临时图标目录。

应用不会向 Codex 索引或任务记录写入数据，不更改审批策略，不代替用户批准操作。SQLite 任务查询使用只读方式。

## 账号与网络

- 不需要 API Key，也不读取 Codex 登录凭据文件。
- 不调用模型 API，不发送遥测，不直接连接外部状态服务。
- 实时数据连接使用本机 Unix socket。
- 点击“打开 Codex”会将对应任务的本地深链接交给系统处理。
- 不配置系统代理、VPN 或 TUN。

Codex 桌面端自身的网络行为由其独立控制，不属于本工具的功能。

## 提交问题时

优先提供操作步骤、应用版本、macOS 和桌面端版本。截图、日志及任务标题可能带有个人或项目内容，请先脱敏；不要提交完整的 `~/.codex`、登录凭据、真实会话日志或访问令牌。

## 仓库内容

源码测试使用合成任务和合成确认请求。个人绝对路径不应硬编码进项目；本地编译会使用路径映射减少构建路径写入。图标生成工具会移除 PNG 和 ICNS 内的文本及 EXIF 元数据。

`.gitignore` 排除了本地产物、日志、缓存和常见凭据文件名。这不能替代实际的提交内容检查；维护者仍需审查新增文件。
